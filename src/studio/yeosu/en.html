Overview

An export company whose website gave buyers no way to get in touch.

Yeosu Saegomak processes cockles from Yeoja Bay in Yeosu and exports them overseas. Its old website had no path from seeing a product to sending an inquiry. I defined that problem and proposed it before our first meeting, then took the work through information architecture and a design system to page design and frontend build.

01 · Problem Definition

I walked into the first meeting with the problem already defined

The proposal opened with a diagnosis, not a mockup. I audited 34 screens of the old site, grouped what I found into four problems, and paired each with a direction. What follows is that proposal, rebuilt for this page.

The old site

Home, menu, production process and recipes, out of 34 screens

0101

Visual and technical decay

  • No HTTPS, so browsers showed security warnings
  • Built on Bootstrap 4, eight years old
  • Pinch-zoom blocked on mobile (an accessibility violation)
  • Unoptimized JPGs everywhere, slowing every page
0202

Misleading information architecture

  • Four "Business" cards on the home page all led to the same page
  • Desktop, mobile and footer menus were defined separately
  • Bulletin-board structure leaked into URLs, confusing users and maintainers
0303

No path to conversion

  • No purchase or inquiry button on the home page
  • No search and no category filters
  • Products, recipes and social were disconnected, so B2B and B2C leads went nowhere
0404

No brand consistency

  • A generic Gnuboard template with no brand identity
  • No brand color or type system
  • Clean waters and fishermen shareholders, the brand’s real assets, never came across
Our Answer

Cut, reduce,
rebuild.

01

User-first design

Drop the supplier-centered menu and rebuild navigation around the tasks visitors look for first.

02

Mobile first

Mobile is 70% of traffic, so design for it first and deliver a fully responsive view.

03

Data-driven IA

Base the structure on GA4 data and heatmaps, not hunches.

04

A design system the team can run

Go beyond one-off pages and hand over a component library the in-house team can combine and extend.

02 · Design Concept

Solid, expert,
and global.

These are the keywords of direction B, the one the client chose. The focus was on looking like a supplier an overseas buyer can trust.

Solid.

Deep navy, a blue gradient and heavy headlines for a trustworthy first impression.

Expert.

The HACCP facility and 13-step production process, shown in real photos.

Global.

An export catalog, markets and certifications that answer a buyer’s questions first.

09 · How I Worked

AI was the tool. I set the direction and the standards

Instead of Figma mockups, I designed directly in code with Codex and Claude Code. Building fast also makes it easy to drift, so I set the standards first and kept the AI inside them.

01 · Specs first

I wrote documents before code

Before building, I wrote specs such as DESIGN SITEMAP COPY TONE MOTION, plus an audit of the old site’s structure. Every later change was measured against them.

02 · People decide

Anything outside the spec, the AI had to stop and ask

So the AI wouldn’t fill gaps on its own, it stopped and asked whenever a decision was needed. We talked briefly, I set the direction, and then it built.

03 · Compare variations

If it wasn’t right, roll back and try another

Even for one production-process banner, I had four versions built (floating cards, diagonal split, timeline, accordion) and chose side by side.

04 · Motion with a reason

I checked the references’ actual code

I opened the scripts of four reference sites (CJ, Hoban Foundation, Samsung Welstory, Haatz) to see which libraries drove their motion, and chose GSAP ScrollTrigger, which three of them used.
