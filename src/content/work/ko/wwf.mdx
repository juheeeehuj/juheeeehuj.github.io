<Block kicker="배경" title="내 후원이 어디에 쓰였는지, 후원자는 알 수 있을까?" layout="side" big>
한국WWF의 FY2025 총수익은 104억 6,200만 원으로 전년보다 37% 늘었습니다. 클릭투기부 앱, 어스아워, 원더플 캠페인 등 참여를 유도하는 채널도 운영하고 있었습니다. 조사에서는 후원을 시작한 뒤의 경험에 주목했습니다. 공개 사이트에서 자신의 후원 구성과 관련 활동을 함께 확인하고, 구성을 조정하는 흐름은 찾기 어려웠습니다.

이 프로젝트는 **후원자가 자신의 후원을 직접 구성하고 계속 관리하는 구조**를 제안하는 것을 목표로 했습니다.

<Figure slot="media" src="wwf/live-home" caption="제안 시안 홈" width={480} />
</Block>

<Block kicker="주요 기능" title="내가 지킬 것을 직접 고르고 구성합니다">
관심 분야와 동물을 선택하고, 항목별 후원 금액을 조정하는 화면을 만들었습니다. 각 항목은 독립된 지정 후원으로 관리하는 구조를 제안하고, 화면에서는 전체 구성과 항목별 비중을 함께 보여주었습니다.

<Figure slot="media" src="wwf/builder-flow" caption="금액 → 분야 → 비율 → 확인 · 시안의 예상 임팩트는 활동을 설명하기 위한 예시입니다." />
</Block>

<Block title="후원 이후에도 확인하고 조정할 수 있도록">
마이페이지는 자신의 후원 구성과 관련 활동을 함께 확인하고, 분야와 금액을 다시 조정하는 출발점으로 설계했습니다. 후원 내역과 인증서 다운로드도 같은 곳에 모아, **후원 이후에도 방문할 이유**를 만들고자 했습니다.

<Block title="금액이 아니라 선택을 공유합니다" layout="side">

<Block kicker="발견 1" title="「바다거북 후원하기」를 눌렀는데, 바다거북이 없습니다" layout="side">
"수달 페이지를 읽고 후원 버튼을 누르면, 후원 화면에 수달이 이미 선택돼 있는가?" 이 질문을 동물 6종에 모두 던져 봤습니다. 통과한 건 2종뿐이었습니다. 나머지 4종은 버튼 이름과 상관없이 같은 일반 캠페인 하나로 이어졌습니다.

이 결과를 바탕으로, 상세 페이지에서 선택한 동물이 후원 화면까지 이어지도록 연결하는 것을 설계 과제로 정했습니다.

<Block kicker="발견 2" title="만들려던 동물 페이지는 이미 있었습니다">
동물 6종의 상세 페이지와 특정 캠페인 후원 화면으로 바로 연결하는 링크 규격이 이미 있었습니다. 동물 페이지는 메뉴에서 두 단계를 거쳐야 접근할 수 있었습니다. 메인 페이지에는 옛 게시판을 가리키는 링크 124개가 남아 있었지만, 콘텐츠는 이미 새 주소로 옮겨진 상태였습니다.

따라서 <strong>기존 콘텐츠를 찾기 쉽게 배치하고, 연결을 바로잡는 일</strong>을 우선했습니다. 동물 페이지는 상위 메뉴에 배치하고, 옛 게시판 링크는 이전된 콘텐츠 주소로 연결하도록 제안했습니다.
</Block>

<Block kicker="분류 체계 진단" title="활동과 후원의 분류를 연결하기 어렵습니다">
WWF 글로벌은 6개, 홈페이지 메뉴는 4개, 연간보고서는 3개 분야로 활동을 나누고 있었습니다. 활동 메뉴의 「생물다양성」과 후원 메뉴의 「멸종위기동물보호」처럼, 관련 활동을 서로 다른 이름으로 부르는 경우가 세 쌍 있었습니다. 후원자가 선택한 항목과 활동 보고의 분류가 다르면, 자신의 후원이 어떤 활동과 연결되는지 파악하기 어렵다고 봤습니다.

<Block kicker="정보구조 재설계" title="활동에서 대상을 고르고, 후원 화면으로 이어지도록">
활동을 읽으며 후원 대상을 고르고, 그 선택을 후원 화면으로 이어주는 것을 설계 원칙으로 삼았습니다. 대메뉴 5개, 하위 25개를 대메뉴 4개와 후원하기 버튼으로 정리했습니다. 활동 분류는 연간보고서의 3분야 구성을 참고하되, 제안 화면에서는 「기후·자원순환·생물다양성」으로 정리했습니다. 동물 6종은 활동 메뉴 바로 아래에 배치하고, 활동에 섞여 있던 캠페인은 참여로 옮겼습니다. 기존 메뉴 25개를 새 위치에 대응시킨 이동표도 만들었습니다.

<Block kicker="핵심 개념" title="화면에서는 비중을 조정하고, 관리 단위는 지정 후원으로" layout="side">
처음에는 월 후원금 하나를 시스템이 활동별 비율에 따라 나누는 구조를 구상했습니다. 기존 후원 관리 시스템과의 연동 부담을 줄이기 위해, 각 항목을 **독립된 지정 후원으로 관리하고 한곳에 묶어 보여주는 구조**로 제안을 바꿨습니다. 화면의 슬라이더와 도넛 차트는 항목별 금액과 전체 비중을 조정·확인하는 인터페이스입니다. 이 구조의 실제 적용 가능성은 후원 관리 시스템과의 연동 검토가 필요한 과제로 남았습니다.

<Block kicker="명칭" title="후원자의 선택이 드러나는 이름을 제안했습니다">
시안에서는 여러 후원을 묶는 구조를 설명하기 위해 「후원 포트폴리오」라는 이름을 썼습니다. 실제 서비스 명칭으로는 「내가 지키는 것들」, 「나의 약속」 같은 후보를 함께 제안했습니다. 수익을 기대하는 투자로 읽힐 수 있는 금융 비유를 줄이고, 자연보전을 위한 선택과 약속을 드러내고자 했습니다.
</Block>

<Block kicker="동작하는 제안서" title="제안서를 쓰기 전에, 주요 화면을 먼저 배포했습니다" big>
주요 화면을 웹 프로토타입으로 만들어 배포한 뒤 제안서를 작성했습니다. 검토자가 링크를 열어 분야 선택, 금액 조정, 구성 확인의 흐름을 직접 조작해 볼 수 있도록 했습니다. 결제와 기존 후원 관리 시스템은 연동하지 않았으며, 동선 검토용 시안이라는 점을 제안서에 명시했습니다.
</Block>

활동 상세는 문제 제기, 원인, 현황 수치, 활동, 성과 순서로 구성했습니다. 페이지 끝의 후원 버튼에서 해당 활동이 선택된 후원 구성 화면으로 이어지도록 구현했습니다. 동물 6종 중 4종에서 상세 페이지의 맥락이 후원 화면으로 이어지지 않았던 문제를 개선하고자 했습니다.

<Block kicker="후원 빌더" title="금액 → 분야 → 비율 → 확인, 4단계">

<Block kicker="확산 구조" title="공유한 선택이 다음 사람의 출발점이 되도록">
후원 완료 시 인증서가 생성되고, 공유 링크에서 같은 구성이 미리 선택된 후원 화면으로 이어지는 흐름을 구현했습니다. 보는 사람이 구성을 그대로 선택하거나 자신에게 맞게 바꾸도록 설계했습니다. 어스아워의 소등 인증, 원더플의 페트병 수거 인증처럼 기존 캠페인의 참여 공유 방식을 후원 경험에도 적용하고자 했습니다.
</Block>

<Block kicker="결과" title="제안 단계에서 마무리">
사이트 조사, 정보구조 재설계, 주요 화면의 웹 프로토타입까지 제작했습니다. 다만 기존 후원 관리 시스템(CRM)과의 연동이 어려워 제안 단계에서 마무리되었습니다. 여러 지정 후원을 한곳에서 관리하는 구조를 실제로 운영하려면, 후원자가 선택한 항목과 금액을 기존 시스템에서 처리할 수 있어야 했습니다.

이 페이지는 제안 과정에서 만든 작업을 정리한 것으로, 한국WWF와 계약한 결과물이 아닙니다. 시안의 사진과 영상은 제안 설명을 위해 임시로 쓴 외부 자료입니다.
</Block>

<Takeaways kicker="회고" title="이번 프로젝트에서 배운 것">
<Takeaway n="01" title="추정 대신 실측이 제안의 힘이 된다">
동물 상세 페이지와 후원 화면을 직접 대조하면서, 어떤 연결을 바꿔야 하는지 구체적으로 설명할 수 있었습니다. 기존 콘텐츠와 링크를 확인한 과정이 제안 범위와 우선순위를 정하는 근거가 되었습니다.
</Takeaway>

<Takeaway n="02" title="화면 뒤의 시스템을 먼저 확인해야 한다">
지정 후원을 묶어 보여주는 구조로 바꾸었지만, 기존 시스템과의 연동 문제까지 해결하지는 못했습니다. 다음에는 화면을 설계하기 전에 후원 항목과 금액을 어떤 단위로 등록·변경할 수 있는지부터 확인하겠습니다. 이를 더 일찍 알았다면 제안의 범위를 다르게 잡았을 것입니다.
</Takeaway>

<Takeaway n="03" title="비영리에서는 지켜야 할 선이 곧 디자인 원칙이다">
실제 성과와 예시 데이터를 구분하고, 인증서에는 금액 대신 선택한 분야를 담았습니다. 비영리 후원의 맥락을 이해하는 과정이 수치 표현과 공유 방식 같은 구체적인 디자인 결정으로 이어졌습니다.
</Takeaway>
</Takeaways>
