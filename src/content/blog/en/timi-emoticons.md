I made TIMI emoticons to use in WITIM: static sets for work and school, plus a set with animation. I gave GPT an existing TIMI image to create expressions and poses for different situations, then used an internal tool to add motion. A developer helped add the finished emoticons to WITIM, where we now use them in real conversations.

## Giving TIMI More Expressions and Gestures

TIMI was created during the [WITIM identity redesign](/en/work/witim-identity/). The character faces the same direction as the user to represent a teammate looking toward the same goal. Its cat silhouette incorporates the shape of a semicolon (;). For this project, I expanded that character into expressions we could use in everyday conversations.

I started by giving GPT an existing TIMI image and asking for expressions and poses based on the character's original appearance. I organized the static emoticons into two sets: one for work and one for school.

## A Set for Work and a Set for School

The work set includes phrases we often exchange during the day, such as “Good morning,” “Checked,” “In a meeting,” and “Thank you.” TIMI sits at a laptop when concentrating and offers a heart to acknowledge someone's hard work. I varied the expressions and props to suit each phrase.

The school set covers assignments, group projects, exams, and the start of a semester, along with phrases like “Anyone up for lunch?”, “Taking the day off class,” and “Professor!!!” Each scene makes the situation easy to recognize, whether TIMI is gathered around a laptop with teammates or slumped over a desk.

## Adding Motion with an Internal Tool

I used an internal tool to create the animated emoticons, adding movements that matched the phrases and situations in the TIMI images made with GPT.

The motion set includes nine expressions: “Got it!”, “Off work!”, “You got this!”, “Checked,” “In a meeting,” “Nice work,” “Thank you,” “Sorry,” and “Looks like overtime.” TIMI runs with a bag when leaving work, brings its paws together to say thanks, and lies collapsed with its soul floating away when facing overtime. The situations established in the static images now have movement, too.

## Using Them in WITIM Chats

A developer helped add the finished emoticons to WITIM. We can now choose from the work, school, and animated sets in the chat window. TIMI started as a brand character and now carries everyday messages like “Checked,” “Thank you,” and “Off work!”
